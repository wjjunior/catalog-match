# Evaluation report

Generated by `pnpm run eval`. Every number below is limited evidence from a small
hand-labeled set: it supports the design choices for this data, and it establishes
neither calibration nor generalization to a catalog this one did not see.

The personalized labels are circular by construction — a person wrote them looking at
the same order history the algorithm reads, and there is no independent ground truth
for what a customer meant. The mitigations are procedural: the labels were frozen
before any parameter was tuned, each carries its reasoning, the held-out set stays
untouched until the end, and constraint preservation is measured against the query
itself rather than against any label. See `docs/eval/golden-rationale.md`.
